# Mobile spike framing

This package retains the bounded newline framer proven by the original M0 macOS
`iroh-spike` prototype. The production transport and pairing flow now live in
`ios/ProgramaSpike`; the completed prototype executable and its direct
`iroh-ffi` dependency were removed. Canonical upstream-wrapper provenance stays
in `vendor/CmuxIrohTransport/PROVENANCE.md`.
